# FlowDesk: Multi-Service Workflow Automation Platform

FlowDesk is an internal ticket and request automation platform designed to streamline operational request triage, prioritization, and legacy system enrichment across multiple distinct backend services.

## Platform Services
- `frontend/`: React + TypeScript (Vite)
- `backend-java/`: Spring Boot 3 Orchestration Service
- `classifier-python/`: FastAPI Keyword & Urgency Classification Service
- `priority-engine-cpp/`: C++17 Binary Max-Heap Priority & Queue Position Engine
- `legacy-hr-soap/`: Mock Legacy HR System (SOAP / WSDL)
